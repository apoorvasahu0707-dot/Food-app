# 🍔 Food Delivery App

A complete food delivery application built with MERN stack.

## ✨ Features
- User Registration & Login
- Browse Restaurants
- Menu Viewing
- Add to Cart
- Order Placement
- Order Tracking
- Payment Integration
- Admin Dashboard

## 🛠️ Tech Stack
- **Frontend:** React, Redux, CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Payment:** Stripe

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/apoorvasahu0707-dot/Food-Delivery.git

# Install dependencies
cd frontend && npm install
cd backend && npm install

# Run the app
cd frontend && npm start
cd backend && npm start
